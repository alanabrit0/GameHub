Sobre o Projeto

O GameHub é uma aplicação web desenvolvida em Angular como atividade prática da disciplina de Desenvolvimento Web. O sistema simula uma plataforma de catálogo de jogos eletrônicos, funcionando sem backend e sem banco de dados, com os dados armazenados em memória através de um Service Angular.

Tecnologias Utilizadas

  • Angular (standalone components)
  • TypeScript
  • Angular Router
  • Services e Injeção de Dependência
  • Two-way Binding com ngModel
  • CSS3 responsivo

Funcionalidades

  • Página inicial com indicadores dinâmicos
  • Catálogo com busca e filtro por categoria
  • Página de detalhes com parâmetro de rota
  • Cadastro de novos jogos via formulário
  • Página institucional

Função dos Componentes, Rotas e Serviços

Os componentes são responsáveis pela interface e comportamento visual de cada parte da aplicação. As rotas gerenciam a navegação entre as páginas sem recarregar o navegador. Já os serviços centralizam a lógica de dados, permitindo que múltiplos componentes acessem as mesmas informações via injeção de dependência.
