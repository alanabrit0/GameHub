# 🎮 GameHub

Plataforma de catálogo de jogos desenvolvida em **Angular** como atividade prática da disciplina de Desenvolvimento Web.

O projeto funciona **sem backend e sem banco de dados**, com os dados armazenados em memória através de um **Service Angular**.

---

## ✨ Funcionalidades

- 🏠 **Página inicial** — apresentação, total de jogos e destaques
- 🎮 **Catálogo** — listagem, busca por nome e filtro por categoria
- 🔍 **Detalhes** — consulta do jogo pela URL (`/jogos/:id`)
- ➕ **Cadastro** — formulário com validação para incluir novos jogos
- ℹ️ **Sobre** — descrição do projeto e identificação do aluno
- 🚫 **Página 404** — rota curinga para endereços inexistentes

---

## 🛠 Tecnologias

- Angular (standalone components)
- TypeScript
- Angular Router
- Services + Injeção de Dependência
- FormsModule (`[(ngModel)]`)
- CSS3 responsivo

---

## 🚀 Como executar

```bash
# instalar dependências
npm install

# rodar o servidor de desenvolvimento
ng serve
```

Depois acesse: **http://localhost:4200**
